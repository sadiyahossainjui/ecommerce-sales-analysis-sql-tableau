# E-Commerce Sales Dashboard

## Project Overview
This project analyzes e-commerce sales performance using Tableau.

The dashboard provides insights into:
- Total Sales
- Total Profit
- Sales by Category
- Profit by Region
- Top Cities by Sales
- Most Sold Sub-Categories

## Tools Used
- SQL
- Tableau
- CSV Dataset

## Key Insights
- Technology category generated the highest sales
- West region contributed the highest profit
- New York City had the highest sales

## Skills Demonstrated
- Data Cleaning
- SQL Analysis
- Data Visualization
- Dashboard Design
- Business Analysis
